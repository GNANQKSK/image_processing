# 🖼️ Image Preprocessing using NumPy & Matplotlib

## 📌 Overview

This project demonstrates fundamental **image preprocessing techniques** using Python.
By leveraging **NumPy** for array manipulation and **Matplotlib** for visualization, various transformations are applied to an input image.

The goal is to understand how images can be modified and prepared for tasks like **computer vision** and **machine learning**.

---

## 🚀 Features

The project performs the following image processing operations:

* ✅ Horizontal Flip
* ✅ Vertical Flip
* ✅ Image Rotation (90°)
* ✅ Brightness Adjustment
* ✅ Gaussian Noise Addition
* ✅ Image Cropping (Center Crop)
* ✅ Grayscale Conversion
* ✅ Binary Thresholding

---

## 🛠️ Technologies Used

* **Python 3**
* **NumPy** – Numerical operations
* **Matplotlib** – Image display and visualization

## 🔍 Explanation of Techniques

* **Flipping**: Reverses image along horizontal or vertical axis
* **Rotation**: Rotates image by 90 degrees
* **Brightness Adjustment**: Increases pixel intensity
* **Noise Addition**: Adds random Gaussian noise
* **Cropping**: Extracts central region of the image
* **Grayscale Conversion**: Converts RGB image to single channel
* **Thresholding**: Converts image into binary format
